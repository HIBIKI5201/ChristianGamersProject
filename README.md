# ChristianGamersProject

## AssetStoreTools（サブモジュール）

`Assets/AssetStoreTools` は private リポジトリ [ChristianGamersProject_AssetStoreTools](https://github.com/HIBIKI5201/ChristianGamersProject_AssetStoreTools) をサブモジュールとして参照している（閲覧権限が必要）。クローン時にサブモジュールも取得する。

```bash
git clone --recurse-submodules https://github.com/HIBIKI5201/ChristianGamersProject.git
# クローン済みの場合
git submodule update --init
```
